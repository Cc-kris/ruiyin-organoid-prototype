# 瑞因生物商城 v2.0 · 类器官全流程原型

在线预览：https://cc-kris.github.io/ruiyin-organoid-prototype/

单页长图原型，包含两部分：

1. **业务流程**（顶部）：查看商品 → 下单 → 合同签署 → 通知实验室/销售 → 销售取样 → 物流取样 → 实验室签收冻存 → 样本列表 → 样本详情 → 检测项目 → 确认订单 → 微信支付 → 报告查询 → 报告详情 → 服务闭环，共 20 个节点，蛇形四行排布。
2. **高保真界面**（下方）：18 屏，严格对照 `conversion-unipp` 小程序源码还原（商品详情、确认订单、微信支付、合同信息、合同详情、签名、线下采样/物流/GMP 信息框、样本列表、样本详情、检测项目、报告列表与详情）。
